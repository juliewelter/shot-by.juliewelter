# shotby.juliewelter — Automotive Photography

Eine responsive Portfolio-Website, inspiriert von der bereitgestellten Vorlage: minimalistischer Header, großes Automotive-Hero-Bild, elegante Serifenschrift und zurückhaltende Farben.

## Dateien
- `index.html` – Seitenstruktur und Inhalte
- `style.css` – Layout, Farben, Typografie und Responsive Design
- `script.js` – mobiles Navigationsmenü und automatisches Copyright-Jahr

## Lokal ansehen
Öffne `index.html` im Browser. Für die Google Fonts und die Beispielbilder ist eine Internetverbindung nötig.

## Auf GitHub veröffentlichen
1. Erstelle auf GitHub ein neues Repository.
2. Lade alle vier Dateien in das Repository hoch.
3. Öffne **Settings → Pages**.
4. Wähle **Deploy from a branch**, danach `main` und `/ (root)`.
5. Speichere. GitHub Pages veröffentlicht die Website unter der angezeigten Adresse.

## Vor dem Veröffentlichen anpassen
- Ersetze „Julie Welter“ und `shotby.juliewelter` bei Bedarf durch deinen Namen.
- Ersetze die Beispielbilder in `index.html` und `style.css` durch deine eigenen Fahrzeugfotos.
- Passe die E-Mail-Adresse `hello@juliewelter.com` und den Instagram-Link an.
- Die Bild-URLs sind externe Demo-Bilder von Unsplash und können jederzeit durch eigene Bilddateien ersetzt werden.
